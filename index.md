# Privacy Policy

**Last updated:** 2025-01-18

This service provides retrieval-augmented responses by querying a privately hosted document system.

## Information Collected
When you use this service, the following information may be processed:
- The text of queries submitted to the service
- Retrieved document excerpts relevant to the query

No personal identifiers are intentionally collected.

## How Information Is Used
Query text is used solely to:
- Retrieve relevant documents from a private knowledge base
- Generate a response to the user

Data is not used for advertising, profiling, or analytics.

## Data Storage and Retention
- Query data is processed transiently and is not permanently stored
- Retrieved document content remains on a privately controlled system
- No data is sold or shared with third parties

## Data Sharing
This service does not sell, rent, or share user data with third parties. Data is only processed to fulfill the user’s request.

## Security
The underlying systems are protected using encrypted transport and restricted access.
